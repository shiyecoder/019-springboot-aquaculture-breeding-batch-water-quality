# 视觉规范（design-system）

## 设计方向
「服务业蓝灰」专业业务系统：数据可读性优先，不做装饰性光效、悬浮球、大面积插画与巨幅英文口号。卡片圆角 6–8px，阴影只用于抽屉与弹窗，正文使用系统中文字体，数字列使用等宽数字（tabular-nums）。

## 色彩
| 用途 | 色值 | 使用位置 |
|---|---|---|
| 主色 | `#284B63` | 侧边栏、主按钮、当前菜单、关键数字 |
| 辅助色 | `#3C6E71` | 次级按钮、筛选选中态、图表第二系列 |
| 页面背景 | `#F6F8F7` | 内容区背景，表格与表单用白色容器 |
| 强调色 | `#355A6B` | 链接、信息提示 |
| 成功 | `#2B7A5A` | 正常、已通过、已关闭 |
| 危险 | `#AD2E3A` | 高风险、驳回、删除确认，只做小面积 |
| 边框 | `#E2E8E6` / 浅边框 `#EFF3F1` | 卡片、分隔线 |

状态不靠颜色单独表达，一律「颜色 + 中文标签」双通道。

## 字体阶梯
| 层级 | 字号 / 行高 | 字重 | 场景 |
|---|---|---|---|
| H1 | 20 / 28 | 600 | 页面标题 |
| H2 | 16 / 24 | 600 | 卡片标题（带 3px 主色左边条） |
| 正文 | 14 / 22 | 400 | 表单、表格、正文 |
| 辅助 | 13 / 20 | 400 | 筛选标签、说明 |
| 微文 | 12 / 18 | 400 | 单位、时间、脚注 |
| 指标数字 | 24 / 32 | 600 | KPI 主值（等宽数字） |

## 栅格与间距
- 左侧菜单 220px，顶栏 56px，内容区外边距 24px
- 卡片间距 14px，卡片内边距 18px（KPI 卡 14px×16px）
- 表单标签宽 110px 右对齐，输入框 380px；搜索下拉框 210px（180–240 区间）
- 首页按 1440×900 设计，6 个指标 + 6 图表控制在一屏内，不出现整页纵向滚动

## 组件基线
| 组件 | 高度 | 圆角 | 说明 |
|---|---|---|---|
| 按钮 | 34px | 6px | 主按钮填充主色，次按钮白底描边，危险按钮红描边 |
| 输入 / 下拉 | 34px | 6px | 聚焦态边框主色，占位文 13px |
| 表格行 | 44px | — | 表头浅底 12.5px，行悬停 `#F8FBFA` |
| 状态标签 | 22px | 10px | 4 类：ok / warn / bad / info / plain |
| 卡片 | — | 7px | 1px 边框，无阴影 |
| 分页器 | 30px | 6px | 右对齐，显示总数与每页条数 |

## 角色视觉区分
- 场长 / 技术员 / 仓管员 / 管理员：后台管理布局（深色侧栏 + 白顶栏 + 灰底内容区）
- 养殖员：门户风格（白色顶栏 + 品牌色 hero + 任务卡片流），强调「今天要做什么」，弱化统计
- 登录页：左侧主色渐变 + 养殖场景说明 + 三项业务数字，右侧 360px 表单，不使用默认表单样式
