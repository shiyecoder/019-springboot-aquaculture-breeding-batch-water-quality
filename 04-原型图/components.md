# 组件规范（components.md）

本文件与 `mock.css`、`design/*.html` 一一对应，前端实现（Element Plus + 自定义样式）按此 1:1 复刻。

## 1. 按钮
| 类型 | 样式 | 用法 |
|---|---|---|
| primary | 填充 `#284B63`，白字，34px 高 | 页面唯一主操作（新建、保存、提交） |
| default | 白底、`#E2E8E6` 描边、深色字 | 次要操作、取消 |
| danger | 白底、`#AD2E3A` 描边与文字 | 作废、删除、驳回，需二次确认 |
| link | 无边框主色文字 | 行内「查看 / 编辑 / 更多」 |
- 行内最多保留「查看 + 2 个高频操作」，其余收进「更多」菜单。
- 危险操作二次确认；普通取消不做强提醒。

## 2. 表单
- 标签 110px 右对齐，必填项标签后加红色 `*`；输入框 380px，短数值 100–120px。
- 下拉框宽 210px（180–240），日期范围用日期区间组件，人员/塘口/批次用可搜索下拉，不用文本框代替。
- 新增/编辑用独立页面或右侧抽屉；关闭前检测未保存内容，复杂表单支持存草稿。
- 校验文案就近展示，红色 12px，出现在字段下方。

## 3. 表格
- 服务端分页，默认 10 条，可切 20/50；切换筛选后页码回到第 1 页。
- 表头不写死宽度，按内容自适应，长文本列给最小宽度并允许横向滚动；编号、状态、日期、操作列单行。
- 状态列用标签，图片列用 64×48 圆角 5px 缩略图（`object-fit: cover`）。
- 空状态说明原因与下一步：「当前筛选条件下无记录，清空筛选或新建水质监测记录」。

## 4. 卡片
- 白底、1px 边框、7px 圆角、内边距 18px；标题 16px 600，左侧 3px 主色竖条。
- KPI 卡：标题 12.5px 灰、数值 24px 主色 + 12px 单位、脚注 11.5px 浅灰。
- 首页 KPI 6 列，图表区 2+1 / 3 列组合。

## 5. 标签
| 类型 | 前景 / 边框 / 底 | 语义 |
|---|---|---|
| ok | `#2B7A5A` / `#BFDCCE` / `#F1F8F4` | 正常、已通过、已关闭、已完成 |
| warn | `#946200` / `#EBD7A8` / `#FDF7E8` | 超限、待处置、待复测、维护中 |
| bad | `#AD2E3A` / `#E5C2C6` / `#FBF1F2` | 高风险、严重超限、驳回 |
| info | `#355A6B` / `#CADCE3` / `#F3F8FA` | 养殖中、执行中、已审批 |
| plain | `#5B7176` / `#E2E8E6` / `#fff` | 已结束、已停用、无数据 |

## 6. 弹窗与抽屉
- 审批/流转统一用抽屉（宽 560px），抽屉内顶部固定展示单据摘要（编号、状态、责任人、时间），底部固定操作区。
- 弹窗仅用于二次确认与轻量表单，最大宽 480px，标题 16px，按钮右对齐。

## 7. 图表
- 折线：主色实线（合格率）+ 辅助色虚线（溶氧均值），平滑曲线、无面积渐变。
- 环图：主色/辅助色/危险色/中性灰四段，中心留白，右侧竖排图例带数量。
- 柱图：自下而上主色渐变，柱宽自适应，X 轴 11px 灰字，最多 8 根。
- 图表点击可带筛选条件跳回明细列表；统计值必须与明细总数一致。

## 8. 时间与数字
- 全系统统一 `yyyy-MM-dd HH:mm:ss`，由 `src/utils/format.js` 的 `formatTime` 输出，页面不得自行拼格式。
- 数量保留 1 位小数、金额千分位、评分 1 位小数；数字列统一 `font-variant-numeric: tabular-nums`。

## 9. 上传
- 一律使用上传组件，禁止填写图片 URL。
- 支持 jpg/png/webp 与 pdf，图片 ≤5MB、附件 ≤20MB，显示进度与删除确认。
- 上传成功返回相对路径 `/uploads/...`，前端用该路径渲染缩略图。
